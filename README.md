# Odin Recipes

A simple recipe website built as part of The Odin Project Foundations course.

## Technologies Used

- HTML5
- Git
- GitHub
- Linux/Xubuntu terminal

## What I Implemented

- Created a homepage with links to different recipes.
- Created individual HTML pages for each recipe.
- Added recipe titles, descriptions, ingredients, and cooking instructions.
- Added images to the recipe pages.
- Used HTML headings, paragraphs, lists, and links to structure the content.
- Used relative links to navigate between the homepage and recipe pages.
- Organized recipe files and images into separate directories.
- Used Git for version control and GitHub to host the project.
